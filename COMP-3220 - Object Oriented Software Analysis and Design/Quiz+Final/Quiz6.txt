Question 1: The Command Pattern encapsulates requests as objects.  
Options: True / False  
Answer: True

Question 2: What can be treated uniformly using the Command Pattern?  
Options: Only singleton objects / Different requests / Only arrays / Primitive data types  
Answer: Different requests

Question 3: In the Command Pattern, what does the Invoker do?  
Options: Creates all receiver objects / Triggers the command execution / Implements business logic directly / Stores application configuration  
Answer: Triggers the command execution

Question 4: What is the main intent of the Command Pattern?  
Options: Create families of related objects / Encapsulate a request as an object / Separate interface from implementation / Provide a simplified interface  
Answer: Encapsulate a request as an object

Question 5: Which design principle is strongly supported by the Command Pattern?

Answer: Encapsulate what varies
