Question 1: The Composite Pattern allows clients to treat what uniformly?  
Options: Individual objects and groups of objects / Classes and interfaces / Methods and variables / Arrays and databases  
Answer: Individual objects and groups of objects

Question 2: Which principle is promoted by the Iterator Pattern?  
Options: Liskov Substitution Principle / Single Responsibility Principle / Dependency Inversion Principle / Open-Closed Principle  
Answer: Single Responsibility Principle

Question 3: In the playlist example where are songs stored internally?  
Options: Array / Tree / Stack / Queue  
Answer: Array

Question 4: Which is an advantage of the Iterator Pattern?

Answer: Hides collection implementation

Answer: False
